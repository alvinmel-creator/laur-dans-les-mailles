# L'Atelier du Fil — Site Web

Site d'exposition et boutique pour créations au crochet artisanal.  
Thème : Blanc / Noir / Doré ✦

---

## 🚀 Déploiement sur Vercel (gratuit, 5 étapes)

### Étape 1 — Créer un compte GitHub
Allez sur [github.com](https://github.com) et créez un compte gratuit.

### Étape 2 — Mettre les fichiers en ligne
1. Sur GitHub, cliquez sur le bouton vert **"New"** pour créer un nouveau dépôt
2. Nommez-le `atelier-du-fil` (ou ce que vous voulez)
3. Cliquez sur **"uploading an existing file"**
4. Glissez-déposez tous les fichiers de ce projet
5. Cliquez **"Commit changes"**

### Étape 3 — Créer un compte Vercel
Allez sur [vercel.com](https://vercel.com) et inscrivez-vous **avec votre compte GitHub**.

### Étape 4 — Connecter votre projet
1. Sur Vercel, cliquez **"Add New Project"**
2. Choisissez votre dépôt `atelier-du-fil`
3. Cliquez **"Deploy"** (pas besoin de changer les paramètres !)

### Étape 5 — C'est en ligne ! 🎉
Vercel vous donne une URL gratuite du type : `atelier-du-fil.vercel.app`

## 📁 Structure des fichiers

```
atelier-crochet/
├── index.html              ← Le site complet (ne pas modifier)
├── data/
│   └── articles.json       ← ✏️ FICHIER À MODIFIER pour gérer les articles
├── images/
│   └── (vos photos ici)    ← Déposez vos photos JPG/PNG ici
├── COMMENT_MODIFIER.md     ← Guide pour modifier le site
└── README.md               ← Ce fichier
```

---

## ✏️ Modifier le contenu

→ Consultez le fichier **`COMMENT_MODIFIER.md`** pour un guide complet et simple.

Le principe : modifiez uniquement `data/articles.json` depuis GitHub (interface web),  
et le site se met à jour automatiquement en 1-2 minutes.

---

## 🌐 Nom de domaine personnalisé (optionnel)

Si vous voulez une adresse comme `atelierdufil.fr` :
1. Achetez un nom de domaine (ex: [OVH](https://www.ovh.com/fr/domaines/) ~10€/an)
2. Dans Vercel > Settings > Domains, ajoutez votre domaine
3. Suivez les instructions pour pointer votre domaine vers Vercel
